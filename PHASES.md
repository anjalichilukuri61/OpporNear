# Local Opportunity Intelligence - Project Phases

## ✅ Completed Phases
- **Phase 1-5:** Initial Setup, Tailwind CSS, Component Structure, Basic Routing, MongoDB setup.
- **Phase 6:** Authentication System (JWT, Login/Register).
- **Phase 7:** Student Profile & Dual-Role System (Student vs Organizer).
- **Phase 7.5:** Organizer Dashboard & Dynamic Opportunity Posting.

## 🚀 Upcoming Phases

### Phase 8: Search & Filter System ✅
- Implemented deep filtering (Search by Keyword, Category, Location, Mode).
- Dynamic real-time sorting.

### Phase 9: Recommendation Engine ✅
- Built an intelligence layer to match students with opportunities based on skills and interests.
- Added visual percentage match scores and explanations (e.g. "✨ Why we recommend this").

### Phase 10: Nearby Opportunity Radar ✅
- Implemented coordinate-based distance calculations (Haversine formula).
- Built a radius slider to filter opportunities within a specific distance (e.g., 50km).

### Phase 11: Omni-Channel Data Ingestion (Bonus) ✅
- Built a Telegram Bot (`OpporNear Radar`) to capture local opportunities from social media.
- Added Regex/NLP to automatically detect categories, cities, and extract application URLs.
